# 展碁 Frontier AI 經銷商藍圖（公開展示版）

網頁：https://tzung27.github.io/weblink-frontier-ai/

公開版已移除 Microsoft 內部數據與展碁內部工作表。Workshop 1 工作表可以試填與試算，但內容不會儲存。客戶與經銷商名稱（Contoso 精密工業、Fabrikam 資訊）、定價與目標數字均為教學示範；Microsoft 計畫與資助依夥伴資格而定，以官方最新公告為準。
