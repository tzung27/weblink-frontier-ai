Part 1

一、活動重點說明

機會的重新定義GitHub Copilot四階段旅程Disti PlanGTM 框架與資助Hack to Build

這場 45 分鐘的線上發表會由 Microsoft Asia AI CoE 的 Dean（Partner Solution Architect）、Valentina（Partner Solution Sales）與合作夥伴行銷團隊主講。核心訊息只有一句：經銷商要從「幫客戶裝技術」轉成「用 AI 幫客戶做生意」，而代理商（Distributor）是把整個經銷商通路帶上這條路的關鍵。

1. 機會的重新定義：從 IT 預算到整體營收

企業平均只把約 5.7% 的營收花在 IT。如果經銷商只談技術導入，能爭取的只有這一小塊；如果改談「用技術改善業務」，可觸及的是其餘 94% 的營運活動。講者估計，換成商業顧問的角度，機會約放大 20 倍。

經銷商分群

Microsoft 依準備度把經銷商分成兩群：已能和 Microsoft 共同建構 AI Offer 的夥伴，以及需要投資培育、重新裝備的夥伴。後者數量較多，潛在機會也較大，正是代理商可以著力的地方。Microsoft 會透過 PDM 與各代理商逐一討論名單與資料。

2. GitHub Copilot：每家經銷商都能成為軟體開發商

講者指出，目前自認能做軟體開發的經銷商不到一成，但 AI 已大幅降低開發門檻。GitHub 的 Agentic DevOps 框架則確保 AI 寫出的程式有品質與治理。這讓「建構方案」成為每家經銷商都能做的事。

Microsoft 希望經銷商跳出舒適圈、做客戶會因此感謝他們的新事情、更重視商業價值，並且從自己開始轉型（Customer Zero）。具體路徑分成四步：

Deploy 部署上線到正式環境，與客戶一起實現價值
Discover 擴展和客戶找出下一個商機，複製到其他客戶

Part 2

二、展碁的策略定位

展碁長期扮演 Microsoft 在台灣的授權與雲端代理角色，手上有大量經銷商與其終端客戶的交易資料。Frontier 計畫要求代理商多做一件事：幫經銷商長出「建構與交付 AI 方案」的能力。建議展碁用三個角色定義自己的 AI CoE：

角色 1

資料驅動的媒合者

把 Microsoft 的 propensity 資料和展碁自己的經銷商交易資料合併，告訴每家經銷商「先找哪 10 個客戶、談哪一個用例」。

角色 2

能力工廠

用三個標準化 Workshop 加上共用的 Sandbox 與範本，讓經銷商在 90 天內完成第一個可交付的 AI 方案。

角色 3

Offer 加速器

幫經銷商把方案包裝成固定範圍的 Offer，並代為申請與串接 Frontier Accelerate、CSP 激勵與 Co-op 資源。

展碁的差異化重點：Microsoft 提供的是亞洲通用的流程。展碁可以做出台灣在地版本（選項 C）：繁體中文教材、台灣產業案例（製造、通路零售、專業服務）、在地法規與資料落地考量，以及新台幣定價範本。
Weblink View展碁規劃觀點

三個角色的投入與回收速度不同，建議依序推進：

  • 資料媒合最快能做：展碁已有經銷商交易資料，結合 Microsoft 傾向資料即可產出名單
  • Offer 加速最直接帶動營收：每個案子對到資助方案，就能縮短客戶決策時間
  • 能力工廠最需要投資：人力與 Sandbox 成本較高，以 Workshop 梯次逐步建立

三、業務面規劃

3.1 經銷商分級與分梯經營

依 Microsoft 的 A/B 分群，再加上展碁自己的觀察，把經銷商分成三個梯隊，每個梯隊有不同的目標與投入方式。

梯隊挑選條件展碁投入90 天目標
T1 共創5–8 家具 Azure Designation 或 Specialization；有開發或 SI 團隊；客戶清單與 propensity 高度重疊白手套陪跑、聯合拜訪、提名 Hack to Build、共同申請 Frontier Accelerate每家 1 個上線的 Agent 方案、2 個付費客戶
T2 示範15–25 家有穩定 SMB 客戶群、M365 或 Azure 基礎；有 1–2 位技術人員三場 Workshop 梯次、範本 Repo、Demo 環境、共同行銷活動每家能獨立 Demo 1 個方案、產生 3 個商機
T3 啟蒙其餘以授權轉售為主，尚無專案能力線上 Live Maker、社群、GitHub Copilot 轉售方案與話術包完成 Live Maker 第 1 場、成為 Customer Zero

3.2 業務點子與做法

點子產業 Offer 套件

針對台灣 SMB 最大的幾個產業，各準備一個「問題清單 + Demo + 定價範本 + 提案簡報」的套件，經銷商不必從零開始。

  • 製造：詢價報價、技術文件問答、品質異常分析
  • 通路零售：門市營運助理、商品知識問答
  • 專業服務：文件審閱、合約摘要、工時報告

點子三段式商業模型

參考簡報的生產力路徑，統一經銷商的報價結構，讓客戶的決策門檻由低到高：

  • 評估 PoV：2–4 週固定價格，可搭配 Frontier Accelerate 售前資助
  • MVP 建置：6–10 週，對應部署資助 T-shirt 級距
  • 代管營運：月費制，持續帶動 Azure ACR 與 CSP 激勵

點子GitHub Copilot 入門組合

把 Copilot 授權轉售與「導入工作坊 + 首個內部專案陪跑」綁在一起賣。簡報的算式是每客戶 $10.4K ARR、16–25% 毛利、約 5.5 倍服務收入，這是經銷商最容易上手的第一筆 AI 生意。

點子資金地圖服務

展碁設立單一窗口，幫經銷商判斷每個案子可以用哪些資源：TPM、Co-op、Frontier Spark、Frontier Accelerate 售前與售後、CSP 激勵、DB 轉換獎金，並追蹤申請進度。經銷商最怕的是不知道有哪些錢可以用。

點子在地化 AI RACE Day
